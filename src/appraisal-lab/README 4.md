# Appraisal Lab

A fully isolated engineering module for synthetic emotion–appraisal classification using Naive Bayes inference.

## What This Is

This lab implements a complete **Layer 1 engineering skeleton** for emotion classification based on appraisal dimensions:

1. **Synthetic dataset generation** — deterministic, seeded PRNG produces 900 labeled rows mapping appraisal vectors to one of six emotions.
2. **Likelihood table construction** — Laplace-smoothed priors and conditional probability tables.
3. **Naive Bayes inference** — log-space computation with log-sum-exp normalization.
4. **Holdout evaluation** — 80/20 split, accuracy, 6×6 confusion matrix, average max probability.

### Important: Synthetic Data Only

The dataset generated by this module is **entirely synthetic**. It is produced by a seeded PRNG using hand-crafted appraisal profiles per emotion. It does **not** originate from human subjects, empirical research, or any external data source. It exists solely for **engineering validation** — to verify that the pipeline compiles, runs deterministically, and produces mathematically correct output.

No research claims are made. No citations are given. This is scaffolding, not science.

## Emotions (6, Locked)

| Emotion   | Key Appraisal Tendencies |
|-----------|--------------------------|
| JOY       | POS valence, MED/HIGH control, HIGH certainty, HIGH goal relevance |
| ANGER     | NEG valence, OTHER agency, MED/HIGH control, HIGH certainty, HIGH arousal |
| FEAR      | NEG valence, LOW control, LOW certainty, HIGH arousal |
| SADNESS   | NEG valence, LOW control, HIGH certainty, LOW/MED arousal |
| DISGUST   | NEG valence, external agency, MED arousal |
| SURPRISE  | LOW certainty, MED/HIGH arousal, mixed valence |

## How to Run

### Prerequisites

The parent project must have TypeScript, ts-node, and Jest configured (they already are).

### 1. Generate the Dataset

```bash
npx ts-node src/appraisal-lab/cli/generate_dataset.ts [seed] [n]
```

- `seed` — integer PRNG seed (default: 42)
- `n` — number of rows (default: 900)
- Output: `src/appraisal-lab/dataset/dataset.generated.json`

### 2. Build the Likelihood Table

```bash
npx ts-node src/appraisal-lab/cli/build_likelihood.ts
```

- Reads `dataset.generated.json`, uses the training split (first 80%).
- Output: `src/appraisal-lab/model/likelihood.generated.json`

### 3. Evaluate on Holdout Set

```bash
npx ts-node src/appraisal-lab/cli/eval_holdout.ts
```

- Reads both generated files, evaluates on the test split (last 20%).
- Prints accuracy, confusion matrix, and average max probability.

### 4. Run Inference on a Single Row

```bash
npx ts-node src/appraisal-lab/cli/run_inference.ts APR-0001
```

- Prints the full posterior distribution for the specified row.

### 5. Run Tests

```bash
npx jest src/appraisal-lab
```

All tests are deterministic and require no generated files on disk.

### 6. Merge ISEAR + Synthetic Datasets

```bash
npx ts-node src/appraisal-lab/cli/merge_datasets.ts
```

- Merges `isear_appraisal_dataset.json` (7,102 ISEAR rows) + `synthetic_disgust_neutral.json` (2,400 synthetic rows)
- Output: `src/appraisal-lab/dataset/isear_appraisal_dataset_extended.json`
- Every row includes provenance fields: `source`, `generator`, `created_at`
- Use `--dry-run` to preview the merge report without writing

## Replacing the Dataset with Real Data

To swap in real labeled data:

1. Prepare a JSON file matching the `AppraisalRow[]` schema defined in `types.ts`.
2. Save it as `src/appraisal-lab/dataset/dataset.generated.json` (or modify the CLI paths).
3. Run `build_likelihood.ts` to retrain.
4. Run `eval_holdout.ts` to evaluate.

The pipeline, model, and evaluation code require **no changes** — only the data file.

## Isolation Guarantees

- **No imports from outside `src/appraisal-lab/`** — the module is fully self-contained.
- **No external dependencies** — only Node.js built-ins (`fs`, `path`) in CLI scripts.
- **No architectural contamination** — does not touch, modify, or depend on any other module in the project.
- **Deterministic** — same seed always produces identical output.
- **Safe to delete** — removing the `src/appraisal-lab/` folder has zero impact on the rest of the project.
